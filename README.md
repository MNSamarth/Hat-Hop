# Hat Hop

Unity 2D greybox starter for CSCI 526. Begin with [the development guide](Docs/Hat_Hop_Development_Guide.md), section 4.

This is an importable source starter. Create a Unity project with your chosen Editor and merge its generated project files into this repository as described in the guide. Then use **Hat Hop > Create Movement Test Scene**.

Included: automatic hops, A/D steering, one buffered larger jump, temporary restart helper, scene-generation menu, development plan and local Git history.

Not yet implemented: room rotation, hazards, exit, scheduling, final UI or Web deployment. Unity compilation and Play Mode tests are pending. See [progress](Docs/PROGRESS.md).

The downloadable archive includes the local `.git` history. Enable hidden-file display if necessary; do not run `git init` again when using that history.
